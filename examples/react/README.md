# Flinders with React

The player on React Router, an offer and a card drawn as React components, a chat answer from `matchWalkthroughs`, and an admin list. Everything is in `src/main.tsx`; the walkthroughs are in `src/walkthroughs.ts`.

This folder has its own dependencies. Build the package first, from its root (`npm install && npm run build`), then here:

```sh
npm install
npm run dev
```

Vite prints the address. Press **Show me** on the offer, or ask the chat "add a note".
