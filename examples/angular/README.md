# Flinders with Angular

The player on Angular's router, an offer and a card drawn as Angular components, a chat answer from `matchWalkthroughs`, and an admin list. Everything is in `src/main.ts`; the walkthroughs are in `src/walkthroughs.ts`.

This folder has its own dependencies. Build the package first, from its root (`npm install && npm run build`), then here:

```sh
npm install
npm run dev
```

Open <http://localhost:4200>. Press **Show me** on the offer, or ask the chat "add a note".
